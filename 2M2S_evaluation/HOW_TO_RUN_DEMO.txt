================================================================================
   AMBA AHB SYSTEMC FORMAL VERIFICATION - ZERO-STEP EVALUATION GUIDE
================================================================================

Everything is 100% portable. NO INSTALLATION OR ADMIN PRIVILEGES NEEDED.
Just copy this entire folder to your laptop or a USB pen drive.

--------------------------------------------------------------------------------
STEP 1: LAUNCH UPPAAL
--------------------------------------------------------------------------------
1. Double-click "LAUNCH_UPPAAL.bat".
2. UPPAAL 4.1.26 will open automatically, with "amba_AHB.uppaal.xml" already loaded!
   (If the batch script doesn't open, just go to the "uppaal" folder and 
    double-click "uppaal.exe" or "uppaal.jar", then File -> Open -> amba_AHB.uppaal.xml).

--------------------------------------------------------------------------------
STEP 2: LOAD THE DEMO QUERIES
--------------------------------------------------------------------------------
1. In UPPAAL, click on the "Verifier" tab (at the top, next to Editor & Simulator).
2. Click "Load Queries" (or File -> Open Queries...).
3. Select "DEMO_QUERIES.q" from this folder.
4. You will see 5 queries appear in the list.
